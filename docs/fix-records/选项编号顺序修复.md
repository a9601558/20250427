# 选项编号顺序修复

## 🐛 问题描述

JSON上传的题目选项编号（A, B, C, D）和实际显示的选项内容不一致。

**症状**：
- 导入的题目选项在前端显示时，字母标签（A, B, C, D）对应的内容可能不正确
- 例如：正确答案应该是A选项的内容，但显示时可能对应到B或C选项

## 🔍 根本原因

### 1. 数据库未排序选项
后端API在返回题目选项时，没有按照 `optionIndex` 字段排序，导致选项顺序随机。

### 2. 前端使用数组索引
前端代码使用数组索引 (`array.map((item, index) => ...)`) 生成字母标签，而不是使用数据库中的 `optionIndex` 字段。

**代码位置**：
```typescript
// src/components/QuizPage.tsx 第2675行
const processedOptions = q.options.map((opt: any, index: number) => {
  return {
    id: optionId,
    text: opt.text,
    isCorrect: opt.isCorrect,
    label: getOptionLabel(index) // ❌ 使用数组索引，而不是opt.optionIndex
  };
});
```

## ✅ 解决方案

### 修复后端排序

在 `server/src/controllers/questionController.ts` 的 `getQuestions` 函数中添加选项排序：

```typescript
const { count, rows: questions } = await Question.findAndCountAll({
  where,
  include: includeOptions,
  limit: Number(limit),
  offset,
  order: [['orderIndex', 'ASC']]
});

// ✅ 手动排序选项（确保 A, B, C, D 顺序正确）
if (include === 'options') {
  questions.forEach((question: any) => {
    if (question.options && Array.isArray(question.options)) {
      question.options.sort((a: any, b: any) => {
        return a.optionIndex.localeCompare(b.optionIndex);
      });
    }
  });
}
```

### 排序逻辑说明

1. **`localeCompare()`**：字符串比较，确保 'A' < 'B' < 'C' < 'D'
2. **在返回前排序**：确保前端收到的选项已经按正确顺序排列
3. **前端数组索引有效**：排序后，数组索引0对应A，1对应B，以此类推

## 🔧 为什么这样修复有效

### 问题流程（修复前）
1. JSON导入时按顺序插入：A, B, C, D
2. 数据库存储时没有保证查询顺序
3. API返回时顺序可能是：B, D, A, C
4. 前端使用数组索引：index=0→B, index=1→D, index=2→A, index=3→C
5. 显示时：A选项显示的是B的内容 ❌

### 修复后流程（修复后）
1. JSON导入时按顺序插入：A, B, C, D
2. 数据库存储 optionIndex：'A', 'B', 'C', 'D'
3. API返回前排序：A, B, C, D
4. 前端使用数组索引：index=0→A, index=1→B, index=2→C, index=3→D
5. 显示时：A选项显示的是A的内容 ✅
