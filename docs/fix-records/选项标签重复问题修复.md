# 选项标签重复问题修复

## 问题描述

在导入JSON题库后，发现选项显示出现重复标签：
- JSON文件中选项text已包含 "A. "、"B. "、"C. "、"D. " 前缀
- 前端代码又通过 `getOptionLabel(index)` 添加了一次标签
- 导致显示时出现 "A A. 选项内容" 的重复现象

## 问题根源

### 1. JSON数据格式
```json
{
  "options": [
    "A. 重新配置 Amazon EFS 以启用最大 I/O。",
    "B. 更新博客站点以使用实例存储卷进行存储。",
    "C. 配置 Amazon CloudFront 分布。",
    "D. 为所有套件内容设置 Amazon CloudFront 分发。"
  ]
}
```

选项文本已经包含了 "A. "、"B. " 等前缀。

### 2. 前端代码重复添加标签

**QuizPage.tsx (第2660-2677行)**
```tsx
const processedOptions = q.options.map((opt: any, index: number) => {
  const optionId = opt.id || `q${q.id}-opt${index}`;
  return {
    id: optionId,
    text: opt.text,  // 包含 "A. xxx"
    isCorrect: opt.isCorrect,
    label: getOptionLabel(index)  // 又生成 "A"
  };
});
```

**QuestionOption.tsx (第53-80行)**
```tsx
const optionLabel = option.label || getOptionLabel(index);
// ...
<div className="圆圈">{optionLabel}</div>  // 显示 "A"
<p>{option.text}</p>  // 显示 "A. xxx"
```

最终导致显示：**圆圈(A) + 文本(A. xxx)** = 重复

## 解决方案

### 核心思路
**优先使用JSON文件中的ABCD标签，没有的情况下再自动赋予**

### 实现步骤

#### 步骤1：修改 QuizPage.tsx
检测选项text是否已包含标签前缀，有则不添加label

```tsx
// 处理选项 - 使用固定的ID生成方式
const processedOptions = q.options.map((opt: any, index: number) => {
  const optionId = opt.id || `q${q.id}-opt${index}`;
  
  // 检测选项文本是否已包含标签前缀（如 "A. " 或 "A："）
  const hasLabel = /^[A-Z][.．。:：]\s/.test(opt.text);
  
  return {
    id: optionId,
    text: opt.text,
    isCorrect: opt.isCorrect,
    // 优先使用原有标签，没有的情况下才添加
    label: hasLabel ? '' : getOptionLabel(index)
  };
});
```

**正则表达式说明：**
- `^[A-Z]`：开头必须是大写字母 A-Z
- `[.．。:：]`：后面跟着英文句号、全角句号、英文冒号或全角冒号
- `\s`：再跟着一个空格
- 匹配示例：`A. `、`B. `、`C：`、`D。`

#### 步骤2：修改 QuestionOption.tsx
根据text是否包含标签，决定是否显示圆圈标签

```tsx
// 获取选项显示标签
const optionLabel = option.label || getOptionLabel(index);

// 检测选项文本是否已包含标签前缀（如 "A. " 或 "A："）
const textHasLabel = /^[A-Z][.．。:：]\s/.test(option.text);

// 如果文本已包含标签，就不显示圆圈标签，只显示文本
// 如果文本不包含标签，显示圆圈标签 + 文本
const displayText = textHasLabel ? option.text : option.text;
const shouldShowCircleLabel = !textHasLabel;

return (
  <div className={`选项容器`}>
    {/* 只在需要时显示圆圈标签 */}
    {shouldShowCircleLabel && (
      <div className={`圆圈标签`}>
        {optionLabel}
      </div>
    )}
    <div className={`flex-1 ${!shouldShowCircleLabel ? 'ml-0' : ''}`}>
      <p className="text-gray-800">{displayText}</p>
      {/* 其他内容... */}
    </div>
  </div>
);
```

## 技术要点

### 1. 正则表达式检测
```typescript
/^[A-Z][.．。:：]\s/.test(text)
```
- 支持多种标签格式：`A. `、`B．`、`C。`、`D：`
- 兼容中英文标点符号
- 只匹配开头的标签，避免误判

### 2. 条件渲染
```tsx
{shouldShowCircleLabel && <div>圆圈</div>}
```
- 根据检测结果决定是否显示圆圈
- 保持代码灵活性，支持两种数据格式

### 3. 样式调整
```tsx
className={`flex-1 ${!shouldShowCircleLabel ? 'ml-0' : ''}`}
```
- 无圆圈时去除左边距
- 保持布局一致性

## 注意事项

### 1. 兼容性
- ✅ 向后兼容：手动添加的题目仍正常显示
- ✅ 向前兼容：JSON导入的题目不会重复标签
- ✅ 数据库无需修改

### 2. 性能影响
- 正则检测在客户端执行，性能影响可忽略
- 每个选项只检测一次，缓存结果
- 无额外网络请求

### 3. 数据格式要求
JSON文件选项格式示例：
```json
{
  "options": [
    "A. 第一个选项内容",
    "B. 第二个选项内容",
    "C. 第三个选项内容",
    "D. 第四个选项内容"
  ]
}
```

**标签格式规则：**
- 必须是大写字母 A-Z 开头
- 后面跟着句号或冒号（英文或中文）
- 标点符号后必须有空格
- 示例：`A. `、`B．`、`C。`、`D：`

### 4. 边界情况
- 如果JSON格式不规范（如 "a. "、"1. "），会被视为无标签
- 如果选项内容包含多个大写字母开头的句子，只检测第一个字符
- 空选项会正常处理，显示空圆圈
