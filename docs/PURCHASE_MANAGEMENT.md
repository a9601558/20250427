# 购买记录管理功能

## 📋 功能概述

管理后台新增了购买记录管理功能，允许管理员查看、搜索和删除所有用户的购买记录。

## ✨ 主要功能

### 1. 查看购买记录
- 显示所有购买记录的详细信息
- 包含用户信息、题库信息、支付状态等
- 计算并显示剩余天数
- 分页浏览（每页20条）

### 2. 搜索功能
- 按用户名搜索
- 按邮箱搜索
- 按题库名称搜索
- 实时搜索结果更新

### 3. 状态筛选
- 全部状态
- 成功支付 (succeeded)
- 待处理 (pending)
- 失败 (failed)
- 已退款 (refunded)

### 4. 删除记录
- 管理员可删除任何购买记录
- 删除前需要确认
- 删除后自动刷新列表

### 5. 统计信息
- 总记录数
- 成功支付数
- 待处理数
- 失败/退款数

## 🎨 界面特点

### 颜色编码
- **绿色边框**：成功支付
- **黄色边框**：待处理
- **红色边框**：失败/退款
- **蓝色边框**：总记录数

### 剩余天数显示
- **绿色文字**：剩余 > 30天
- **黄色文字**：剩余 7-30天
- **红色文字**：剩余 < 7天

### 状态徽章
- **绿色徽章**：成功
- **黄色徽章**：待处理
- **红色徽章**：失败
- **灰色徽章**：已退款

## 📡 API端点

### 获取购买记录
```
GET /api/admin/purchases
```

**查询参数：**
- `page`: 页码（默认：1）
- `limit`: 每页数量（默认：20）
- `search`: 搜索关键词（可选）
- `status`: 状态筛选（可选）

**响应：**
```json
{
  "success": true,
  "data": {
    "purchases": [...],
    "currentPage": 1,
    "totalPages": 5,
    "totalCount": 100
  }
}
```

### 删除购买记录
```
DELETE /api/admin/purchases/:purchaseId
```

**响应：**
```json
{
  "success": true,
  "message": "购买记录已删除"
}
```

## 🔐 权限要求

- 需要管理员权限
- 所有API调用都需要 JWT token
- 非管理员用户无法访问此功能

## 🚀 使用方法

1. 登录管理后台
2. 点击左侧菜单的「购买记录管理」
3. 使用搜索框查找特定记录
4. 使用状态下拉菜单筛选
5. 点击删除按钮删除记录（需确认）

## ⚠️ 注意事项

1. **删除操作不可恢复**：删除购买记录后无法恢复，请谨慎操作
2. **级联删除**：删除记录不会影响用户账户或题库
3. **访问权限**：删除购买记录后，用户将失去对该题库的访问权限
4. **分页加载**：大量记录时会自动分页，提高加载速度

## 🎯 使用场景

1. **退款处理**：用户申请退款后删除购买记录
2. **错误订单**：修正错误的购买记录
3. **测试数据清理**：清除测试环境的购买记录
4. **用户管理**：处理特殊用户的购买历史
